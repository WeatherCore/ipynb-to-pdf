支持什么内容？
  • nbformat v3 / v4 笔记本（老 Anaconda 导出也能转）
  • GFM Markdown 全要素：标题、表格、列表、引用、删除线
  • 笔记本内嵌 HTML：<font>、<center>、<style> 等原样生效
  • 代码单元格：In [n]: 提示符 + 语法高亮（Jupyter 经典配色）
  • 输出：stream 文本、HTML 表格、matplotlib 图片、错误堆栈
  • 数学公式：$…$ 行内与 $$…$$ 块级（KaTeX）
  • 图片：内嵌附件、base64 图、OSS/图床外链
  • <!-- CELL_BREAK --> 标记自动转为分页符
不支持什么？
  • 交互式 widget（ipywidgets）：静态 PDF 无法承载，自动跳过并提示数量
  • JavaScript 交互输出、iframe 嵌入内容
  • 需要联网执行的代码（转换不运行任何代码，只渲染已保存的输出）
文件会被上传吗？

不会。解析与渲染全部在你的浏览器里完成，.ipynb 文件不离开你的电脑。

「转换为 PDF」由真正的 PDF 引擎生成（无打印对话框）：本地走 npm run pdf-server 启动的无头 Chromium 服务，部署后走你自己的 Cloudflare Worker。两者产出的 PDF 均带侧边栏书签大纲与页脚页码。

导出的 PDF 怎么调纸张和边距？

两条引擎路径均为 Letter 纸张、2cm 边距、页脚页码（第 X 页 / 共 Y 页），并自动按标题层级生成 PDF 侧边栏书签。无需任何手动配置。
